# Écoleta — app

Aplicativo (React + Vite) e servidor Express do Écoleta: login, cadastro e mapa com a rota do caminhão.

A documentação completa (configuração, como rodar, APIs e solução de problemas) está no [README principal](../README.md).

Resumo, dentro desta pasta:

```bash
# a configuração fica no .env da raiz do projeto (veja o README principal)
npm install
npm run dev            # http://localhost:5173
npm test               # testes automatizados
```
